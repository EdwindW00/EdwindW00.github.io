# Edwin's Tools

Verzamelwebsite met een overzicht van losstaande webtools, elk in hun eigen repository:

- [Edwin's Budgettool](https://github.com/EdwindW00/DreSo-Budgettool) — budgettool voor interieur- en verbouwingsprojecten.
- [KDV Rekentool](https://github.com/EdwindW00/KDV-Rekentool) — optimale werk-privébalans met kinderen in de kinderopvang.
- [Opvangvergelijker](https://github.com/EdwindW00/Opvangvergelijker) — netto kosten van KDV, gastouder en oppas-aan-huis naast elkaar.
- [Uren- en honorariumplanning](https://github.com/EdwindW00/Fee-Resourceplanner) — planning van uren, tarieven en honorarium per fase, met Gantt en PACO-export.

Gehost op `https://edwindw00.github.io/`. Nieuwe tools toevoegen: voeg een kaart toe in `index.html`
die linkt naar `https://edwindw00.github.io/<repo-naam>/`.
